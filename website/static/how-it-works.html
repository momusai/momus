Two promises, and only one of them is obvious

    

      Everything above exists to keep these true. The first is the one people expect
      a scanner to make. The second is the one that decides whether it is safe to
      trust.
    

    

      

        
Never cry wolf

        
A model that refuses is never reported vulnerable

        

          A refusal usually mentions the thing it is refusing. Check whether the
          reply contains PJ204_HIT and you
          flag the well-behaved model — the exact opposite of the truth.
        

        

          So compliance has to be proven: the reply must be the
          token, not mention it. Where that is impossible, a second model reads the reply
          and must quote real evidence for its verdict.
        

      

      

        
Never say safe

        
A target that was never tested never comes back clean

        

          Wrong URL, expired key, a login page, a streaming endpoint. Every attack
          “fails”, and a careless scanner prints 200 safe, 0 vulnerable —
          a perfect score for something it never reached.
        

        

          That one gets somebody breached, so inconclusive is the default answer,
          not the leftover. Anything unrecognised lands there, and a run that decided
          nothing exits with an error rather than a tick.
        

      

    

  


  


  
  

    
Three values, not two

    

      Detectors combine with and /
      or /
      not. Because one branch can be undecided,
      the logic is three-valued — and the tables are built so uncertainty spreads rather
      than getting quietly rounded away. Note the one that surprises people:
      not(undecided) is still undecided.
    

    

  


  


  
  

    
What it actually throws at you

    

      200 attacks, written as YAML rather than code, so adding one needs no Go.
      Mapped to the OWASP LLM Top 10 and MITRE ATLAS.
    

    

    

      By how they decide: 126 prove compliance with a canary and confirm
      it with the judge, 44 are judged alone, and 30 rest
      on an unguessable canary by itself — safe without a judge precisely because a
      refusal cannot be the token.
